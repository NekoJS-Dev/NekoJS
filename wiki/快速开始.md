# 快速开始

本页带你从零跑起第一个 NekoJS 脚本。

## 1. 安装前置

NekoJS 依赖 [Graal](https://www.curseforge.com/minecraft/mc-mods/graal)（提供 GraalJS 运行时）。

1. 下载与你所用 MC / NeoForge（或 Cleanroom）版本匹配的 **Graal** 和 **NekoJS**。
2. 把两个 jar 都放进 `mods/` 文件夹。
3. 启动游戏。

> ⚠️ 版本必须匹配。发布页面会标注每个 NekoJS 对应的 MC / 加载器版本。

## 2. 目录结构

首次启动后，游戏根目录下会自动生成 `nekojs/` 文件夹：

```text
.neko_probe/                # 自动生成的 .d.ts 类型声明（与 nekojs 同级）
nekojs/
├── startup_scripts/        # 启动脚本：注册物品/方块等（改了要重启游戏）
│   └── tsconfig.json
├── server_scripts/         # 服务端脚本：配方、事件监听（支持 /nekojs reload）
│   └── tsconfig.json
├── client_scripts/         # 客户端脚本：GUI、粒子、按键（支持 reload）
│   └── tsconfig.json
├── test_scripts/           # 测试脚本：通过 /nekojs test 显式运行
├── node_modules/           # 外部纯 JS npm 依赖
├── assets/                 # 资源
├── data/                   # 数据包
└── config/
    └── engine.toml         # 引擎配置（沙盒开关等）
```

详见 [脚本基础](脚本基础)。

## 3. 第一个脚本

在 `nekojs/server_scripts/` 下新建 `hello.js`：

```javascript
// server_scripts/hello.js

// 监听「服务端启动完成」事件
ServerEvents.started(event => {
  console.info('[NekoJS] 服务端脚本已加载！')
})
```

进世界，或执行 `/nekojs reload`。日志里应出现 `[NekoJS] 服务端脚本已加载！`。

## 4. 改一个配方

```javascript
// server_scripts/recipes.js

ServerEvents.recipes(event => {
  // 删除所有原版木棍配方
  event.remove({ output: 'minecraft:stick' })

  // 加一个：1 个圆石 → 4 个木棍
  event.shaped('4x minecraft:stick', [
    'C'
  ], {
    C: 'minecraft:cobblestone'
  }).id('nekojs:cobble_to_sticks')
})
```

执行 `/nekojs reload`（NeoForge 配方改动可能需重新进世界；1.12.2 Cleanroom 支持真正的配方热重载）。

详见 [配方系统](配方系统)。

## 5. 注册一个新物品

```javascript
// startup_scripts/my_items.js

RegistryEvents.item(event => {
  event.create('mymod:cool_gem')
    .maxStackSize(16)
    .rarity('rare')
})
```

> ⚠️ 启动脚本注册的内容**改了要重启游戏**，`/nekojs reload startup` 会重跑脚本但注册表已冻结。

详见 [注册新内容](注册新内容)。

## 6. 开启 IDE 智能提示

1. 在游戏内执行 `/nekojs probe`，会重新生成 `.neko_probe/` 下的 `.d.ts`。
2. 用 VS Code 打开 `nekojs/server_scripts/`（或对应目录），里面的 `tsconfig.json` 已自动关联 `.neko_probe` 类型库。
3. 现在你输入 `ServerEvents.` 会自动补全事件名，`Item.of(` 会显示参数类型。
