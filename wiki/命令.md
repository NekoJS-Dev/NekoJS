# 命令

NekoJS 注册了一个根命令 `/nekojs`，需要权限等级 LEVEL_GAMEMASTERS（op 2 及以上）。

## 命令一览

| 命令 | 作用 |
|---|---|
| `/nekojs reload` | 重载**服务端**脚本（默认）。NeoForge 上还会重跑配方脚本。 |
| `/nekojs reload <type>` | 重载指定类型脚本。`<type>` ∈ `startup` / `server` / `client` / `test` |
| `/nekojs reload <type> <file>` | 重载单个脚本文件（路径相对该脚本类型根目录；文件名支持 TAB 补全） |
| `/nekojs test` | 运行 `nekojs/test_scripts/` 下所有脚本（TEST 脚本上下文） |
| `/nekojs error` | 报告当前是否有脚本错误 |
| `/nekojs view_all_errors` | 把完整错误列表以 UI 形式发送给玩家 |
| `/nekojs editor` | 为执行者打开游戏内工作区编辑器 UI |
| `/nekojs probe` | 重新生成 `.neko_probe/` 类型声明（`.d.ts`）并写 jsconfig 路径 |

## reload 详解

### `/nekojs reload`（默认 server）

最常用。热重载服务端脚本（配方、事件监听）。**事务式**：先把脚本加载进候选 Context，全部成功才替换旧的；失败则保留旧 Context，不会进入半坏状态。

### `/nekojs reload <type>`

| type | 行为 |
|---|---|
| `server` | 同上 |
| `client` | 重载客户端脚本（仅 integrated client 上可用） |
| `test` | 重载测试脚本 |
| `startup` | 重跑启动脚本，但**注册表新增需重启游戏**。reload 主要用于调试脚本逻辑 |

### `/nekojs reload <type> <file>`

只重载单个文件，比全量 reload 快。例：

```
/nekojs reload server recipes.js
/nekojs reload client tooltips.js
```

文件路径相对该脚本类型根目录（如 `recipes.js` 相对 `nekojs/server_scripts/`）。文件名支持 TAB 补全。

## 配方 reload 的平台差异

| 平台 | `/nekojs reload server` 对配方的效果 |
|---|---|
| **Cleanroom 1.12.2** | ✅ **完整热重载**：解冻注册表 → 移除旧 nekojs 配方 → 重跑配方脚本 → 重新冻结 → 通过 mixin 自动刷新 HEI/JEI 配方面板 |
| **NeoForge（26.x / 1.21.1）** | ⚠️ 会重跑配方脚本，但配方在数据包加载阶段已固化，运行时 reload **不会真正刷新**配方面板。改完配方建议**重新进世界**。reload 不会报错，只是配方面板可能不变。 |

## probe 详解

`/nekojs probe` 会：

1. 收集当前所有绑定、事件、适配器、配方 schema、注册表内容。
2. 反射相关 Java 类，生成 `.d.ts` 到 `.neko_probe/`。
3. 原子交换：先生成到 `.staging`，成功后替换 `.neko_probe`，旧的备份到 `.old`。失败则保留旧输出。
4. 更新 `jsconfig.json` 路径。

> 加了新 mod、新事件、或脚本注册了新内容后，建议跑一次 `/nekojs probe` 刷新类型声明。详见 [Probe 类型生成](Probe-类型生成)。

## editor 详解

`/nekojs editor` 打开游戏内工作区编辑器 UI，可以在游戏里浏览/编辑脚本文件（适合不方便切窗口的场景）。功能比外部 IDE 简单，复杂编辑仍推荐 VS Code。

## error / view_all_errors

- `/nekojs error`：快速报告当前是否有错误（yes/no + 简短摘要）。
- `/nekojs view_all_errors`：把完整错误列表发到聊天栏/UI，便于排查。

脚本出错不会崩溃游戏——错误会被捕获、记录到 `logs/nekojs/<type>.log`，出错脚本被标记 disabled 直到 reload 成功清除标记。

## 权限

所有 `/nekojs` 子命令都需要 **op 2 及以上**（`LEVEL_GAMEMASTERS`）。在单人世界里，开启作弊的玩家自动满足。
