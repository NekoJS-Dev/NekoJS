# 注册新内容

在 `startup_scripts/` 里通过 `RegistryEvents` 注册新物品、方块、实体类型；用 `GoalEvents` 给已有实体追加 AI。注意：**注册类改动后要重启游戏**，`/nekojs reload startup` 会重跑脚本但注册表已冻结。

## RegistryEvents.item —— 注册物品

```javascript
// startup_scripts/my_items.js
RegistryEvents.item(event => {
  event.create('mymod:cool_gem', builder => {
    builder
      .maxStackSize(16)
      .rarity('rare')
      .fireResistant()
  })
})
```

### ItemBuilder 方法

| 方法 | 说明 |
|---|---|
| `maxStackSize(int)` | 最大堆叠数 |
| `maxDamage(int)` | 最大耐久 |
| `fireResistant()` | 抗火 |
| `rarity('common' \| 'uncommon' \| 'rare' \| 'epic')` | 稀有度 |
| `glowing()` | 发光 |
| `food(cb)` | 设为食物（接 `FoodBuilder` 回调） |
| `group(tabId)` | 分配到创造标签页（如 `'minecraft:building_blocks'` 或自定义 tab id） |
| `burnTime(ticks)` | 燃料燃烧时间（>0 时物品可作熔炉/高炉/烟熏炉燃料） |

> 物品 tooltip 不在 builder 上设置——用客户端事件 [`ItemEvents.tooltip`](事件参考#itemevents) 按物品 id 添加：`ItemEvents.tooltip('mymod:cool_gem', event => event.add('第一行'))`。

> `group` 让物品出现在创造物品栏。tab id 可用原版标签页（`minecraft:building_blocks` / `minecraft:tools` / `minecraft:food` 等）或 `RegistryEvents.creativeModeTab` 注册的自定义标签页 id。

> 注册后物品的默认材质/模型按 `assets/mymod/textures/item/cool_gem.png` / `assets/mymod/models/item/cool_gem.json` 解析（标准原版资源路径）。可在 `nekojs/assets/` 下放资源。

## RegistryEvents.block —— 注册方块

```javascript
// startup_scripts/my_blocks.js
RegistryEvents.block(event => {
  event.create('mymod:custom_block', builder => {
    builder
      .hardness(3.0)
      .resistance(6.0)
      .sound('stone')
      .requiresTool()
      .lightLevel(7)
      .item(item => item.rarity('rare').maxStackSize(16)) // 可选：配置自动创建的 BlockItem
  })
})
```

### BlockBuilder 方法

| 方法 | 说明 |
|---|---|
| `hardness(float)` | 硬度 |
| `resistance(float)` | 抗爆 |
| `unbreakable()` | 不可破坏（硬度 -1） |
| `lightLevel(int)` | 亮度 |
| `mapColor(name)` | 地图颜色（如 `'dirt'`/`'water'`/`'gold'`/`'color_red'`/`'nether'`） |
| `renderType('solid' \| 'cutout' \| 'cutout_mipped' \| 'translucent')` | 客户端渲染层（做玻璃等透明方块） |
| `requiresTool()` | 需要正确工具才能掉落 |
| `noItem()` | 不生成 BlockItem |
| `item(cb)` | 配置自动创建的 BlockItem（接 `ItemBuilder` 回调，可设 rarity/stackSize 等） |
| `sound('wood' \| 'stone' \| 'metal' \| 'glass' \| 'grass' \| 'gravel' \| 'wool' \| 'sand' \| 'snow' \| 'amethyst')` | 声音类型 |

默认会自动生成一个同名 BlockItem（出现在物品栏，前提是用 `group` 或标签页分配）。`item(cb)` 可定制其属性；`noItem()` 则完全不生成物品。

> **renderType 平台差异**：`renderType` 在 1.21.1 上会实际生效（经 `ItemBlockRenderTypes.setRenderLayer` 应用渲染层）。26.x（1.21.5+）的渲染为**模型驱动**——没有代码 API，需要在模型 JSON 的贴图引用里加 `"force_translucent": true`（或使用带 alpha 的贴图）才会走 translucent 渲染；`renderType(...)` 在该平台仅记录不生效。自定义流体的液体方块在 1.21.1 上默认按 translucent 渲染。

## RegistryEvents.fluid —— 注册流体

注册一个**完整可用的自定义流体**：可在世界放置、会流动、可用桶舀取。系统自动注册流体类型 + source/flowing 流体 + 液体方块 + 桶物品。

```javascript
// startup_scripts/my_fluids.js
RegistryEvents.fluid(event => {
  event.create('mymod:molten_iron', builder => {
    builder
      .density(3000)        // 密度（比水重）
      .viscosity(2000)      // 粘度（流动更慢）
      .temperature(1500)
      .lightLevel(12)       // 发光
      .slopeFindDistance(3) // 流动距离
      .explosionResistance(50)
      // .bucket(false)     // 默认自动注册桶（mymod:molten_iron_bucket）
      // .block(false)      // 默认自动注册液体方块（mymod:molten_iron）
  })
})
```

### FluidBuilder 方法

| 方法 | 说明 |
|---|---|
| `displayName(key)` | 翻译 key（如 `fluid.mymod.molten_iron`） |
| `density(int)` | 密度（>1000 比水重下沉，<1000 上浮） |
| `temperature(int)` | 温度 |
| `viscosity(int)` | 粘度（越大流得越慢） |
| `lightLevel(int)` | 发光等级 |
| `canConvertToSource(bool)` | 是否可无限生成源（默认 false，对标 1.21 原版水） |
| `slopeFindDistance(int)` | 流动寻路距离（默认 4） |
| `levelDecreasePerBlock(int)` | 每格下降等级（默认 1） |
| `explosionResistance(float)` | 抗爆（默认 100） |
| `tickRate(int)` | 流动 tick 间隔（默认 5） |
| `bucket(bool)` | 是否注册桶（默认 true，`<id>_bucket`） |
| `block(bool)` | 是否注册液体方块（默认 true，id = 流体 id） |

自动注册产物：`<id>`（source 流体）、`flowing_<id>`（flowing 流体）、`<id>`（液体方块）、`<id>_bucket`（桶）。流体纹理/模型需自行放资源包（26.x 走模型驱动，1.21.1 走 `IClientFluidTypeExtensions`）。

**Cleanroom 1.12.2 也支持** `RegistryEvents.fluid`，API 略有差异：

```javascript
RegistryEvents.fluid(event => {
  event.create('nekojs:molten_iron', fluid => {
    fluid
      .stillTexture('minecraft:blocks/water_still')   // 静止纹理
      .flowingTexture('minecraft:blocks/water_flow')  // 流动纹理
      .density(2000).viscosity(4000).temperature(1200)
      .luminosity(8)
      .material('water')      // 'water' | 'lava'
  })
})
```

1.12.2 自动注册：`FluidRegistry` 条目（流体名取 id 的 path 部分）+ 液体方块（`<id>`，`BlockFluidClassic`）+ 桶（`<id>_bucket`）。注意 1.12.2 的桶引用**方块**而非流体，因此 `block(false)` 时会同时禁用桶。

## RegistryEvents.enchantment —— 注册附魔（仅 NeoForge）

```javascript
// startup_scripts/my_enchantments.js
RegistryEvents.enchantment(event => {
  event.create('mymod:ice_bane', enchantment => {
    enchantment
      .supportedItems('#minecraft:enchantable/weapon')  // 可附魔物品标签
      .weight(5)                                        // 权重（附魔池概率）
      .maxLevel(3)                                      // 最大等级
      .minCost(5, 5)                                    // 最小消耗 base + perLevel
      .maxCost(20, 5)                                   // 最大消耗 base + perLevel
      .anvilCost(2)                                     // 铁砧成本
      .slots('mainhand')                                // 生效槽位组
  })
})
```

| 方法 | 说明 |
|---|---|
| `supportedItems(tag)` | 可附魔的物品标签（如 `'#minecraft:enchantable/weapon'`，可不带 `#`） |
| `weight(int)` | 权重（默认 1） |
| `maxLevel(int)` | 最大等级（默认 1） |
| `minCost(base[, perLevel])` / `maxCost(base[, perLevel])` | 消耗曲线 |
| `anvilCost(int)` | 铁砧成本 |
| `slots('mainhand' \| 'armor' \| 'any' \| ...)` | 生效槽位组 |

> 默认不挂附魔效果组件（可注册、可附魔/书本/互斥，但无实际效果）；1.21+ 的附魔效果需经 `EnchantmentEffectComponents`，暂不开放。

## RegistryEvents.creativeModeTab —— 注册创造标签页（仅 NeoForge）

```javascript
// startup_scripts/my_tabs.js
RegistryEvents.creativeModeTab(event => {
  event.create('mymod:cool_tab', tab => {
    tab
      .title('我的模组')
      .icon('mymod:cool_gem')           // 图标（物品 id 或 ItemStack）
      .add('mymod:cool_gem')            // 添加条目
      .add('mymod:custom_block')
  })
})
```

注册后可在 `ItemBuilder.group('mymod:cool_tab')` 里引用该标签页。

## RegistryEvents.mobEffect / potion / soundEvent / particleType / paintingVariant / villagerType（仅 NeoForge）

```javascript
// 状态效果
RegistryEvents.mobEffect(event => {
  event.create('mymod:shock', effect => {
    effect.category('harmful')   // 'beneficial' | 'harmful' | 'neutral'
      .color(0x00FF00)           // HUD 图标底色
  })
})

// 药水（可含多个效果实例）
RegistryEvents.potion(event => {
  event.create('mymod:shock_potion', potion => {
    potion.effect('mymod:shock', 600, 0)      // (效果, 时长tick, 等级)
    potion.effect('minecraft:speed', 3600, 1, false, true)
  })
})

// 声音
RegistryEvents.soundEvent(event => {
  event.create('mymod:thunder_clap', sound => {
    sound.fixedRange(64)
  })
})

// 粒子类型
RegistryEvents.particleType(event => {
  event.create('mymod:sparkle', particle => {
    particle.overrideLimiter(true)
  })
})

// 画作变体
RegistryEvents.paintingVariant(event => {
  event.create('mymod:epic_painting', painting => {
    painting.width(2).height(2).assetId('mymod:epic')
  })
})

// 村民类型
RegistryEvents.villagerType(event => {
  event.create('mymod:miner')
})
```

> 以上 6 种仅 NeoForge（26.x / 1.21.1）；Cleanroom 1.12.2 不支持。

## RegistryEvents.entityType —— 注册实体类型

注册一个**脚本化实体**（继承内置的 `NekoScriptMob`，是个 `PathfinderMob`），可在脚本里定义它的属性和 AI。

```javascript
// startup_scripts/my_entity.js
RegistryEvents.entityType(event => {
  event.create('mymod:test_mob', builder => {
    builder
      .category('creature')        // 实体类别
      .size(0.6, 1.8)              // 碰撞箱宽 × 高
      .trackingRange(8)            // 追踪范围
      .updateInterval(3)           // 同步间隔
      .attributes(a => a            // 属性
        .maxHealth(18)
        .movementSpeed(0.25)
        .followRange(24)
        .attackDamage(3)
      )
      .goals(g => g                 // AI 目标
        .floatInWater(0)
        .panic(1, 1.2)
        .randomStroll(5, 1.0)
      )
  })
})
```

### EntityTypeBuilder 方法

| 方法 | 说明 |
|---|---|
| `category(...)` | 实体类别 |
| `size(width, height)` | 碰撞箱尺寸 |
| `trackingRange(int)` | 追踪范围 |
| `updateInterval(int)` | 同步间隔（tick） |
| `receiveVelocityUpdates(bool)` | 接收速度更新 |
| `fireImmune()` | 抗火 |
| `noSave()` | 不存盘 |
| `noSummon()` | 禁止自然生成 |
| `spawnEgg(bgColor, hlColor)` | 自动注册 `<id>_spawn_egg` 生物蛋（见下方说明） |
| `attributes(cb: EntityAttributeBuilderJS)` | 设属性 |
| `goals(cb: GoalBuilderJS)` | 设 AI 目标 |

### EntityAttributeBuilder 方法

| 方法 | 说明 |
|---|---|
| `maxHealth(v)` | 最大生命 |
| `movementSpeed(v)` | 移动速度 |
| `followRange(v)` | 追踪范围 |
| `attackDamage(v)` | 攻击伤害 |

### 生物蛋（spawnEgg）

`builder.spawnEgg(背景色, 高亮色)` 会自动注册 `<id>_spawn_egg` 物品（可用 `/give @s nekojs:test_mob_spawn_egg` 获取），右键即生成该实体：

```javascript
RegistryEvents.entityType(event => {
  event.create('mymod:test_mob', builder => {
    builder.category('creature').size(0.6, 1.8).spawnEgg(0x8a6f4d, 0xffe2b3)
  })
})
```

版本差异：

| 平台 | 行为 |
|---|---|
| NeoForge 1.21.1 | 颜色**生效**：`template_spawn_egg` 模型自动生成，按注册颜色运行时染色 |
| NeoForge 26.1 / 26.2 | 颜色参数被忽略（新版本无运行时染色，纹理数据驱动）；NekoJS 自动生成默认蛋模型（占位为鸡蛋纹理），自定义外观请在资源包里提供 `<ns>:textures/item/<id>_spawn_egg.png` 或覆盖对应模型 JSON |

## GoalBuilder —— AI 目标

`goals(g => ...)` 回调里用的 builder，每个方法都接受可选的 `priority` 参数（数字越小优先级越高）。

| 方法 | 说明 |
|---|---|
| `floatInWater(priority?)` | 水中漂浮 |
| `randomStroll(speed)` / `randomStroll(priority, speed)` | 随机走动 |
| `meleeAttack(speed, longMemory)` / `meleeAttack(priority, speed, longMemory)` | 近战攻击 |
| `panic(speed)` / `panic(priority, speed)` | 恐慌逃跑 |

链式调用，最后 NekoJS 自动注册（无需手动 `.register()`）。

## GoalEvents —— 给已有实体追加 AI

不创建新实体，而是给**已有实体类型**（包括原版）加 goal。

```javascript
// startup_scripts/pig_goals.js
GoalEvents.register(event => {
  event.forType('minecraft:pig', goals => {
    goals
      .panic(0, 2.0)        // 优先级 0，速度 2.0
      .randomStroll(6, 0.8)  // 优先级 6，速度 0.8
  })
})
```

`event.forType` 第一个参数可以是 `EntityType` 对象或 id 字符串（如 `'minecraft:pig'`）。

## 资源与本地化

注册的内容需要配套资源：

- **物品/方块材质**：`nekojs/assets/<mod>/textures/item/<name>.png`、`textures/block/<name>.png`。
- **模型 JSON**：`nekojs/assets/<mod>/models/item/<name>.json` 等。
- **语言文件**：`nekojs/assets/<mod>/lang/zh_cn.json`，键名通常是 `item.<mod>.<name>`、`block.<mod>.<name>`、`entity.<mod>.<name>`。

```json
// nekojs/assets/mymod/lang/zh_cn.json
{
  "item.mymod.cool_gem": "炫酷宝石",
  "block.mymod.custom_block": "自定义方块",
  "entity.mymod.test_mob": "测试生物"
}
```

## 平台差异

1.12.2（Cleanroom）的实体/方块 API 与现代版本有差异；实体类别枚举、属性注册方式可能不同。多数物品注册 API 一致。
