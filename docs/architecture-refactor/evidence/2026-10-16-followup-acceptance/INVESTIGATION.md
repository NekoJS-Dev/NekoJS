# 性能失败后的定向实验

日期：2026-10-16。[原正式复测](PERFORMANCE.md)中的当前候选重载失败保持不变。以下均为诊断，不能替代原政策样本。

## 撤回共享解析实验

两个静态校验器在模块准备阶段分别解析同一份 JavaScript。主代理试作单次解析、顺序运行 Binding/Callback 检查的内部入口，保留当前 generation 的 schema 与独立错误集合；Luna xhigh 只读复核未发现 AST 写入或诊断顺序差异。原 JS 与转译后的 JS 分支本来互斥，本实验不声称消除了同一调用对原始源、产物的双重检查。入口执行器重读源码后的单独校验也未合并。

定向检查共 60 tests、0 failure/error/skip，覆盖旧的两个校验器、语言分流及新增的诊断内容/顺序等价、previous→candidate→previous schema 变化。首次实验测试对旧实现不支持的 callback 别名提出了额外断言，失败后改用直接 callback 成员访问；原始失败日志保留，未把它归因于共享解析。初始临时 classpath 任务误用于 buildSrc 的失败也保留，修正后离线执行检查通过。

独立 Java 25 JVM 对同一套六个实际 fixture 源码、相同的合成动态 Binding schema 交替比较两个旧入口与共享入口。各入口先预热 1000 轮，随后十个配对，每腿 200 轮，奇偶配对交换先后顺序。每套六脚本均值：旧入口 2.3790 ms，共享入口 2.2509 ms，节省 **0.1281 ms / 5.38%**。这是组件实验，schema 不含真实 Minecraft 类型和事件元数据，不能当作整机收益。

该收益不足以解释正式重载的上百毫秒差距，未保留新增抽象。所有生产改动及实验测试已撤回，完整 patch、新文件、测量与失败日志保留于归档；没有把实验算成生产修复。

## 二十次重载阶段计时

在干净 `0965e29b` 专属工作区仅临时修改 `ReloadProgressTracker` 和命令边界，使用唯一 `[DEBUG-CLOSEOUT-16]` 标记。记录初始候选，再执行二十次间隔三秒的重载，逐次保留命令 UTC 窗口。均成功提交、正常 RCON 停服，控制器直接退出码 0。

上述阶段来自临时计时，有 instrumentation 开销；不等同于 CPU 独占时间。RCON 还包括外部 Python 客户端、命令调度和其他边界，不把未覆盖差值归因于某个阶段。本 fixture 的领域收集没有脚本提供的新动态/交易声明；0.0574 ms 只约束这套复现负载，不能外推复杂整合包。

同一轮 JFR 仅分析二十个命令窗口：服务端 CPU/native 样本 137 个，其中脚本重载链 89 个、配方重新应用 37 个。路径规范化/验证、模块准备与执行出现较多；后续调查保持符号链接和 trust 边界检查，不用跨代真实路径缓存换取成绩。静态校验仍不是足以解释全部差距的证据。

首次控制器准备误用主机默认 GBK 读取 UTF-8 源码，在游戏启动前失败；后续显式 UTF-8 准备后才执行测量。两次记录均保留。环境快照由抽取的采样函数生成，其 `git rev` 字段为空；精确基线提交由控制器校验、`jvm.json` 和两文件 SHA/patch 另行绑定，不补写原快照。

临时计时源码已撤回，专属工作区恢复干净 `0965e29b`。该轮编译输出曾包含计时，下一次运行正式候选前须重新构建并核对类绑定，不能沿用计时输出冒充正式制品。

## 声明和客户端调查输入

Luna xhigh 只读调查完整 26.1.2 严格 TSC：server/startup 为 744/745 条。除缺模块/导出外，TS2344 为 199 条、TS2304 为 139 条、TS2416 为 88 条；相同诊断文本分别去重为 120、79、77 组，不是独立 Java 类型数量。具体原因包括枚举声明缺失 `Enum<Self>` 实例继承、同包依赖在扫描深度边界未生成、脚本输入别名与 Java override 签名冲突。尚未用 opaque 空壳、Any、扩大扫描或屏蔽诊断替代修复。

客户端只读缓存盘点确认：现有 `build` 下 1.21.1 / 26.1.2 的 issue36 数据目录和 NeoForge 服务端安装不足以直接复用为完整私有客户端；没有对应 launcher profile 与 native 全套缓存。26.2 的首帧证据保持已验范围，其他客户端项继续开放。该结论仅限已调查的 `build` 路径，未宣称系统其他缓存不存在资源。
