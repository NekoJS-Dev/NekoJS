# Functional followups beyond acceptance work

## Scope and ranking

This is source-backed feature analysis, not an implementation or compatibility certification. It excludes earlier acceptance/release work, nested/sequenced recipes, non-default mirror/shrink controls, and additional targeted events/cancellation. Ranking is engineering judgment about user benefit and reuse of existing ownership seams, not measured effort or a commitment. No builds, tests, configuration changes, gameplay checks, commits, or publication were performed; cited tests are specifications, not newly executed evidence.

| Priority | Functional addition | Practical benefit |
|---|---|---|
| 1 | Registry-aware structured item/component inputs | Component-bearing items behave consistently across supported input forms and versions |
| 2 | Machine-readable runtime outcomes | Tools distinguish script errors, retained operation status, and TEST completion from assertion success |
| 3 | Bounded package-root entry resolution | Ordinary JavaScript packages can use an explicit package entry without rewriting imports to subpaths |
| 4 | Publish captured legacy builder types into native registration | Supported addon content builders become usable through existing startup registration |
| 5 | Exact 64-bit MixinJS value transport | Hooks containing primitive Java long values can be represented without precision loss |

These proposals extend current converters, queries and lifecycle boundaries; none requires another evaluator, recipe engine, registry owner, or test runner.

## 1. Registry-aware structured item/component inputs

**Already implemented:** modern stack object conversion consumes `components` and applies a native patch. Component-bearing string inputs on 1.21.1 already use a per-call registry provider, which resolves current server/client registries and falls back to builtins rather than retaining old world holders. Recipe serialization also uses borrowed registry operations. Sources: [modern object conversion](../../src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackAdapter.java#L118-L151), [1.21.1 string conversion](../../versions/1.21.1/src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackAdapter.java#L86-L95), [registry provider](../../src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackStringRegistries.java#L10-L22), [recipe serialization](../../src/main/java/com/tkisor/nekojs/wrapper/event/server/RecipeEventJS.java#L193-L199).

**Missing:** modern structured patches parse with plain `JsonOps.INSTANCE`; the generic codec fallback also fixes parsing to plain JSON operations. Registry-dependent values therefore lack the context available at the string/event seams; this does not mean every component codec fails. The 1.21.1 object converter reads item/id/count but never consumes a components member, which its input declaration likewise does not advertise. Sources: [patch decoder](../../src/main/java/com/tkisor/nekojs/js/type_adapter/DataComponentsAdapter.java#L19-L26), [codec fallback](../../src/main/java/com/tkisor/nekojs/js/type_adapter/CodecAdapter.java#L65-L68), [1.21.1 object converter](../../versions/1.21.1/src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackAdapter.java#L110-L135), [1.21.1 input shape](../../versions/1.21.1/src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackAdapter.java#L34-L50).

**Bounded reuse:** supply registry operations at the existing native conversion seam, resolving them per call rather than storing world providers or importing Minecraft into common contracts. Preserve startup timing differences: modern registration already delays component decoding until native registry operations are available, whereas the 1.21.1 startup implementation decodes immediately and explicitly rejects unsupported component codecs. Sources: [modern delayed installation](../../src/main/java/com/tkisor/nekojs/wrapper/registry/gen/ItemComponentSupport.java#L20-L40), [1.21.1 installation](../../versions/1.21.1/src/main/java/com/tkisor/nekojs/wrapper/registry/gen/ItemComponentSupport.java#L15-L47), [registry lifetime](../../src/main/java/com/tkisor/nekojs/js/type_adapter/ItemStackStringRegistries.java#L10-L22).

**Legacy nuance:** item and processing-output structural shapes omit a patch field, but those shapes do not prove every runtime input is rejected. Native runtime values delegate to canonical conversion, and processing-output runtime values use the original component wrapper; only its JSON-constant path separately applies the literal shape gate. Improve declarations/constants only alongside real conversion support, not a fabricated mod-specific alias. Sources: [native delegation](../../addons/nekujs/src/main/java/com/tkisor/nekujs/recipe/value/LegacyRecipeComponents.java#L282-L301), [custom runtime versus constants](../../addons/nekujs/src/main/java/com/tkisor/nekujs/recipe/value/LegacyRecipeComponents.java#L343-L375), [item shape](../../addons/nekujs/src/main/java/com/tkisor/nekujs/recipe/value/LegacyRecipeComponents.java#L489-L494).

## 2. Machine-readable runtime outcomes

### Runtime diagnostics and retained operation status

**Already implemented:** successful MCP calls include `structuredContent`. Context reports environment/index and live-control availability. Frozen runtime diagnostic records and bounded, metadata-only control audit records already exist, including late-completion transitions that do not rewrite an earlier timeout response. Sources: [MCP responses](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringMcp.java#L190-L204), [context](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringRuntime.java#L95-L102), [control availability](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringRuntime.java#L169-L175), [diagnostic record](../../common/src/main/java/com/tkisor/nekojs/core/error/ScriptDiagnosticRecord.java#L10-L67), [late transitions](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringControl.java#L280-L315), [audit projection](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringControl.java#L351-L365).

**Missing:** advertised read operations are context/capabilities/schema/resolve/members/query/batch, not runtime-diagnostics or retained operation-status lookup. Bundled documentation resources do not provide that state. Extend the existing read query core to project current root errors and retained operation metadata, not another tracker or raw-log endpoint. Sources: [MCP operations](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringMcp.java#L22-L23), [HTTP operations](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringHttpServer.java#L80-L89), [documentation resources](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringMcp.java#L206-L210), [root records](../../common/src/main/java/com/tkisor/nekojs/core/lifecycle/NekoRuntimeRoot.java#L650-L668).

Keep redaction, epoch fencing and bounded history. The audit capacity is 64, and copies exclude commands, arguments, feedback and exception details. A lookup must distinguish unknown/evicted records rather than promise durable history or completion from retired runtimes. Sources: [capacity](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringControl.java#L29-L38), [epoch checks](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringControl.java#L225-L240), [metadata-only copies](../../common/src/main/java/com/tkisor/nekojs/authoring/AuthoringControl.java#L351-L365).

### TEST run results, not another test engine

**Already implemented:** TestJS counts passes/failures, throws on failures, and exposes/logs summaries. Managers reload TEST scripts and drain timers. Sources: [assertion accounting](../../common/src/main/java/com/tkisor/nekojs/bindings/static_access/TestJS.java#L14-L34), [summary accessors](../../common/src/main/java/com/tkisor/nekojs/bindings/static_access/TestJS.java#L104-L123), [TEST execution](../../common/src/main/java/com/tkisor/nekojs/script/ScriptManager.java#L1692-L1742).

**Missing:** root `runTests()` returns configured/completed booleans, and the command says “TEST scripts completed,” not that assertions passed. Timer draining has a cap and interruption path, but the result has no settled/pending distinction. Extend the same result/formatting path with per-run assertion counts, execution failure and bounded pending-work status. Do not relabel completion as success or claim all asynchronous work settled. Sources: [runTests](../../common/src/main/java/com/tkisor/nekojs/core/lifecycle/NekoRuntimeRoot.java#L461-L473), [result record](../../common/src/main/java/com/tkisor/nekojs/core/lifecycle/NekoRuntimeRoot.java#L640-L647), [formatter](../../common/src/main/java/com/tkisor/nekojs/core/lifecycle/RuntimeCommandResultFormatter.java#L50-L56), [timer bound](../../common/src/main/java/com/tkisor/nekojs/script/ScriptManager.java#L1720-L1742).

## 3. Bounded package-root entry resolution

**Already implemented:** ordinary bare/scoped/subpath resolution exists below configured node_modules; direct files, supported extension candidates and directory index candidates work. ESM and require already use this shared resolution path. Sources: [bare modules](../../common/src/main/java/com/tkisor/nekojs/core/module/NekoModuleResolver.java#L66-L107), [candidate resolution](../../common/src/main/java/com/tkisor/nekojs/core/module/NekoModuleResolver.java#L120-L147), [ESM linker](../../common/src/main/java/com/tkisor/nekojs/core/module/esm/NekoEsmLinker.java#L266-L273), [require route](../../common/src/main/java/com/tkisor/nekojs/core/module/NekoScriptModuleLoaderHost.java#L213-L222).

**Missing and bounded addition:** directory resolution does not read package.json or select its main entry. A package exposing only lib/start.js through main needs an explicit subpath today; an index candidate is selected without consulting main. Add a deliberately limited entry policy inside that resolver, specifying precedence, extensions and cycle handling while preserving canonical file identity and package/game-directory containment. Do not call this full Node resolution: conditional exports, native addons and wider Node API compatibility are not implied by a main branch. Sources: [complete directory path](../../common/src/main/java/com/tkisor/nekojs/core/module/NekoModuleResolver.java#L120-L147), [identity/containment](../../common/src/main/java/com/tkisor/nekojs/core/module/NekoModuleResolver.java#L150-L177).

## 4. Publish captured legacy builder types into native registration

**Already implemented:** the legacy bridge invokes original plugins' registerBuilderTypes and captures their actual classes/factories. Its catalog enforces duplicates and exposes snapshots, but explicitly refuses native installation with NEKO-4253. Sources: [capture ownership](../../addons/nekujs/src/main/java/com/tkisor/nekujs/bridge/LegacyRuntimeBridge.java#L20-L52), [catalog/rejection](../../addons/nekujs/src/main/java/dev/latvian/mods/kubejs/registry/BuilderTypeCatalog.java#L12-L43).

**Missing and bounded addition:** capture is not publication into usable startup builders; the current bridge has no consumer of this catalog beyond the original registration call. Adapt an explicitly supported subset into the existing RegistryTypesPoint and RegistryObjectBuilder lifecycle so the native event discovers/configures/queues it. Reuse native ownership/order/conflict rules; do not call legacy createRegistryObjects or install a second registry pipeline. Sources: [collection site](../../addons/nekujs/src/main/java/com/tkisor/nekujs/bridge/LegacyRuntimeBridge.java#L24-L52), [native type Point](../../src/main/java/com/tkisor/nekojs/wrapper/registry/gen/RegistryTypesPoint.java#L18-L85), [native builder lifecycle](../../src/main/java/com/tkisor/nekojs/wrapper/registry/gen/RegistryObjectBuilder.java#L15-L65), [event lookup](../../src/main/java/com/tkisor/nekojs/wrapper/registry/gen/RegistryEventJS.java#L173-L242).

This is higher integration scope than reporting: configuration, construction and additional-object semantics must be mapped deliberately. Successful plugin discovery or recipe conversion does not establish content-builder installation, and this proposal does not promise all KubeJS addon builders work. Sources: [explicit rejection](../../addons/nekujs/src/main/java/dev/latvian/mods/kubejs/registry/BuilderTypeCatalog.java#L41-L43), [additional-object contract](../../src/main/java/com/tkisor/nekojs/wrapper/registry/gen/RegistryObjectBuilder.java#L35-L65).

## 5. Exact 64-bit MixinJS value transport

**Actual boundary:** primitive JVM J descriptors are rejected. Carrier boxing has no Long arm; callback numeric conversion passes through double and covers B/S/I/F/D; generated declarations have no bigint/long case. This is an unsupported ABI, not an undocumented implemented feature. Sources: [descriptor admission](../../common/src/main/java/com/tkisor/nekojs/core/mixin/MixinPlan.java#L45-L68), [boxing](../../common/src/main/java/com/tkisor/nekojs/core/mixin/tool/MixinCarrierWriter.java#L97-L104), [callback conversion](../../common/src/main/java/com/tkisor/nekojs/core/mixin/MixinInvocation.java#L64-L95), [declaration mapping](../../common/src/main/java/com/tkisor/nekojs/probe/backend/typescript/MixinHookDeclarations.java#L49-L62).

**Bounded addition:** define one exact signed-64-bit script representation before admitting J. A bigint-oriented contract would require coordinated descriptor admission, carrier boxing/local-slot handling, callback range conversion and TypeScript declarations. Do not route full-range longs through JavaScript number/double or enable only the parser. These existing four owners are extension seams, not grounds for another injection engine. This feature is independent of the previously discussed production/loader acceptance work.

**Clarification of earlier wording:** hook arguments are currently read-only, both at runtime (the proxy array rejects writes) and in generated declarations. An earlier reference to testing “parameter modification” must not be read as implemented argument mutation; argument observation and supported return/cancellation behavior are different contracts. This note does not add argument mutation as a previously delivered feature. Sources: [runtime argument view](../../common/src/main/java/com/tkisor/nekojs/core/mixin/MixinInvocation.java#L24-L32), [readonly declaration](../../common/src/main/java/com/tkisor/nekojs/probe/backend/typescript/MixinHookDeclarations.java#L18-L20).

## Recommendation

Start with structured component conversion and runtime outcome reporting. Then choose package entry resolution or legacy builder publication according to actual users' dependency/content needs. Exact long transport is narrower and should remain explicitly unsupported until the existing pipeline has one coherent representation. These are proposals only; the citations establish current behavior and limits, not delivered functionality.
