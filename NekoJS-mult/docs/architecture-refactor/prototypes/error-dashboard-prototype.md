## VS Code 演示边界

“在 VS Code 中打开”只对已知样例路径和有效行号显示定位计划；Unknown、虚拟位置及未知行号禁用。白名单只识别演示数据，不表示已经确认本地文件存在。

弹窗明确说明“示例，实际需本地存在路径”。报告相对路径不等于本机绝对路径；原生实现仍须安全解析、确认本地映射和真实文件存在。远端、未知、虚拟位置不能直接映射成本地文件。只展示 DTO 的行号，不从 `fullDetails` 推断结构化列号。

本 HTML 不调用 URI、shell 或 VS Code，不检测安装状态，不实现游戏协议，也不读取／写入真实脚本或发起 fetch。边界依据见 [VS Code 定位调研](../evidence/vscode-error-location-research.md)。

## 数据与实现范围

仅使用 `id/path/line/count/message/fullDetails` 六字段。样例代表逻辑服务端错误；没有 local/server 筛选、时间、severity、generation、ScriptType、编辑器、修复建议、保存、上传、回滚或远端下载。

CSS 方块背景明确是模拟。Fabric 当前仅保留聊天降级，不承诺同款 GUI。所有交互状态只在内存中；收起／关闭不重新渲染详情。
