## 目标与范围

允许用户在已安装实现中稳定选择前端，而不依赖插件加载顺序、语言 ID、实现类名或对象标识。复用既有 ScriptCompilerRegistry 和 Point 的注册／冻结所有权，不另建运行时所有者或全局注册表。

- 评审可选具名前端注册重载与只读候选目录；完整语言插件及旧编译器适配器均需可选具名注册。旧注册入口继续自动解析，保持源码和二进制兼容。
- 前端 ID 合法且唯一；自动解析的 replaceLanguage 语义与显式候选目录分离，覆盖后仍可显式选回内置前端；加入内置回退候选不能改变自动优先级。
- 配置选择必须进入原子捕获及缓存身份，避免相同语言 ID 的不同实现混用产物；入口、依赖及 CJS/ESM 共用选择。
- 评审标准引擎配置中的选择表示、不可变注入、候选发现和失败定位；与 D3 共用唯一配置模型，不独立发布重复的 frontend-only 配置别名。
- 未配置时保持自动解析；显式未知或不兼容提供者不能静默回退。配置不可读／格式错误时失败关闭属于待审合同变更，不得顺带纳入 #69。
- 配置更改需完整进程重启；普通 reload 不重建 Plugin Runtime 或冻结目录。不负责下载插件、加载任意类或替换 GraalJS。
